This guide is for Tapcart App Studio. You do not need to write code or use the Tapcart CLI. Fast Bundle 2.0 prepares and publishes the block; you add it to the product page and publish.

Bundles on Tapcart are the **same bundles** as your Shopify store. Add to cart goes to **Tapcart's native cart**. The Fast Bundle 2.0 block attaches the discount info — no extra merchant step. The discount still applies in Shopify checkout. Keep the Fast Bundle 2.0 automatic discount **Active** in Shopify admin → **Discounts**.

```
Your Tapcart app
  └─ Product page
       └─ Fast Bundle 2.0 block
            └─ Bundle widget
                 Shopper selects options and taps Add to Cart
            Tapcart adds the lines (with discount info attached)
```

## What Fast Bundle 2.0 sets up

Before you start, Fast Bundle 2.0 will have:

1. Enabled bundle data for your store
2. Published the **Fast Bundle 2.0** block to your Tapcart app (App Studio → **My Blocks**)
3. Pre-configured the block so it points at your store — you normally do not set URLs

If any of these are missing, contact your Fast Bundle 2.0 account manager.

## Prerequisites

- Fast Bundle 2.0 installed (see [Getting started](/getting-started))
- At least one **Active** bundle in Fast Bundle 2.0 admin
- Tapcart **Enterprise** with App Studio access (required for custom blocks)
- Access to [Tapcart App Studio](https://studio.tapcart.com)

## Add the block

<Steps>
  <Step title="Confirm the block">
    Open App Studio, select your app, go to **Screens → My Blocks**, and confirm **Fast Bundle 2.0** is listed. If it is not, Fast Bundle 2.0 has not published it yet.
  </Step>
  <Step title="Place it on the product page">
    Open the **Product Detail Page** template. Click **Add Block**, choose **Fast Bundle 2.0**, and drag it where the widget should appear — typically below product details or above the native Add to Cart button.
  </Step>
  <Step title="Optional settings">
    In most cases leave the right-hand panel as Fast Bundle 2.0 pre-filled it. You do not set a product ID; Tapcart supplies the current product.

    | Setting | Description |
    | --- | --- |
    | App origin override | **Leave blank** (blank = production). Only set this if Fast Bundle 2.0 support asks you to. |
    | Bundle handle, Bundle type | **Leave blank.** They don't currently limit which bundles show; every bundle that matches the product renders. |
    | Initial height in px | Fallback height until the widget reports its size — what you see on the **static App Studio canvas**. On device the widget sizes to content. Default `600`. |
    | Debug mode | Console logs and an on-screen diagnostic panel. **Leave blank in production.** |
  </Step>
  <Step title="Save and publish">
    Save the screen, then **Publish** the app (or push a preview build).
  </Step>
</Steps>

<Warning>
  If **App origin override** is set to the wrong value, the widget stays blank. Clear the field to use production.
</Warning>

## Verify

App Studio has two previews, and they are not the same:

- **The canvas** (drag-and-drop layout) is static. The widget uses a **fixed placeholder height**. You may see a caption like _"Bundle preview — sizes to content on device."_ That is expected.
- **"Preview your app"** and the **installed app** run the widget for real. It auto-sizes, including when a product has more than one bundle.

Always verify in **Preview your app** or on a device.

1. Open a product that has an **Active** bundle.
2. The widget should appear, sized to its content.
3. Select options and tap the bundle **Add to Cart** button.
4. Tapcart cart should show every bundle line.

Then complete a test order. Each bundle line in Shopify admin → **Orders** should show `__FB_ATC_UID` and the discount. If items are in the cart with no discount, see [Troubleshooting](/troubleshooting).

## Troubleshooting

| Symptom | Likely cause | What to do |
| --- | --- | --- |
| Blank space | Endpoint not enabled, or block not pointing at the store | Contact Fast Bundle 2.0 support |
| Console: refused to connect | Tapcart WebView blocking the widget origin | Contact Fast Bundle 2.0 support (Tapcart allowlist) |
| Blank space where the widget should be | No bundle matches this product | In Fast Bundle 2.0 admin, include this product in a bundle and set it **Active** |
| Fast Bundle 2.0 not in My Blocks | Block not published to this app | Contact your Fast Bundle 2.0 account manager |
| Items in cart, no discount | Fast Bundle 2.0 automatic discount inactive, or property stripped | Confirm **Discounts** is Active; see [Troubleshooting](/troubleshooting) |

Bundle changes in Fast Bundle 2.0 admin can take up to about **6 minutes** to show in the app.

<Note>
  Placement is product page only. The block does not replace Tapcart's native Add to Cart button. In the app, bundles sell one-time only (no subscription plans), and bundles shown as a popup or hidden on product pages don't appear. **Show on → Selected products' pages** isn't applied in the app. Your Shopify web storefront is unchanged.
</Note>

## CLI (optional)

If your team has Tapcart Enterprise CLI access and wants to host the block in your own repo, ask Fast Bundle 2.0 for the block project. Most merchants do not need this — Fast Bundle 2.0 publishes the block for you.
