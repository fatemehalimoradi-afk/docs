Fast Bundle 2.0 works on a Shopify theme out of the box. For other surfaces, pick a path:

| Path | You build |
| --- | --- |
| **Bundle type** on a Shopify theme | Nothing — fill in a form |
| [**Custom widget**](/widget) on a Shopify theme | The widget's HTML and CSS |
| [**Headless embed**](/headless-bundles-api) | An iframe and a cart handler |
| [**Tapcart**](/tapcart) | Nothing — place the block |
| [**Headless Data API**](/headless-bundles-api) | The whole UI, price display, discount tag, and cart |

| | Bundle type | Custom widget | Headless embed | Tapcart | Data API |
| --- | --- | --- | --- | --- | --- |
| Selection state | Fast Bundle 2.0 | Fast Bundle 2.0 | Fast Bundle 2.0 | Fast Bundle 2.0 | **You** |
| Prices and savings shown | Fast Bundle 2.0 | Fast Bundle 2.0 (you draw them) | Fast Bundle 2.0 | Fast Bundle 2.0 | **You** |
| `__FB_ATC_UID` tag | Fast Bundle 2.0 | Fast Bundle 2.0 | Fast Bundle 2.0 writes it; **you** keep it | Fast Bundle 2.0 | **You** write it |
| Adding lines to the cart | Fast Bundle 2.0 | Fast Bundle 2.0 | **You** | Tapcart | **You** |
| Discount at checkout | Fast Bundle 2.0 | Fast Bundle 2.0 | Fast Bundle 2.0 | Fast Bundle 2.0 | Fast Bundle 2.0 |

With the Data API, your displayed price only approximates checkout, which always wins — prefer the embed unless you need full UI control. Bundles are edited only in Fast Bundle 2.0 admin.
