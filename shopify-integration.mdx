| Piece | Role |
| --- | --- |
| Theme app extension | Draws the widget on product pages |
| Cart line-item property `__FB_ATC_UID` | Tags each bundle line for checkout |
| Discount function | Applies the rewards at checkout, on products and shipping |

[Headless](/headless-bundles-api) and [Tapcart](/tapcart) don't need the theme app extension.

## The app embed

Turn on the **Bundles** embed in **Online Store → Themes → Customize → App embeds**. After saving a bundle, reload once the editor shows **Synced** (some pages may keep a cached copy for up to 5 minutes).

### Which bundles show on a product page

A bundle shows when it is **Active**, **Show this bundle on product pages** is on, and a product set matches the page (the product or a variant, a collection it belongs to, an **every product** set, or its own [Bundle as Product](#bundle-as-product) page). With **Show on → Selected products' pages**, only the selected sets count. Bundles whose tiers can't be met with sellable products are skipped (console: `BUNDLE_UNSELLABLE`). Matches show in **Display priority** order (lower first).

## Placing the widget

Fast Bundle 2.0 places each widget at the first of:

1. The theme's app block for that bundle (see below).
2. The bundle's **Custom element** selector.
3. The bundle type's selector from **Settings → Default widget position → Advanced**.
4. The store's **Default widget position**.
5. The theme's add-to-cart button, found automatically.
6. The end of the product section or page (the console warns — set a widget position).

A bundle-type or store selector uses its own **Position**; with **Each bundle's own position**, the bundle's **Above** or **Below** applies.

Widgets on one spot stack with a 16px gap (`--nameless-bundle-gap`). **Hide elements** lists (per bundle, per bundle type, and store-wide) all apply.

### The app block

1. In the bundle editor, open **App block** and **Copy display handle**.
2. In the theme editor, open a product template.
3. Add the **Bundle** app block where the widget should go.
4. Paste the handle into **Bundle metaobject handle**.

Leave it empty to show whichever bundles match.

### Pop-up

With **Display as → Pop-up**, the theme's add-to-cart button opens the widget in a dialog. Only the highest-priority pop-up shows.

## Add-to-cart method

**Using widget button** (default): the widget's own button adds the bundle. **Using theme button**: the theme's add-to-cart button adds the bundle instead of the product. With the theme button:

- The theme form's variant and quantity feed the page product's set. On a Bundle as Product page, quantity N adds N bundles.
- The widget draws no button of its own.
- Only the first bundle in priority order takes the button; others that would take it aren't shown.
- Best for **a main product plus optional picks**. A bundle made only of a collection list isn't supported.
- The theme's cart drawer opens after the add.
- **Settings → Widget button action → Advanced → Don't use the theme's add-to-cart button** turns this off for every bundle; a Bundle as Product page still turns an add of its product into the bundle.

Developers can wrap this pipeline — see [Resolver stages](/resolver-stages).

## After add-to-cart

**Settings → Widget button action** sets what happens after the widget's button adds a bundle:

| Action | Result |
| --- | --- |
| **Cart drawer** (default) | Opens the cart drawer of common themes and cart apps; otherwise goes to the cart page |
| **Cart page** | Goes to `/cart` |
| **Checkout** | Goes to checkout |
| **Do nothing** | Stays; the cart count refreshes |

A custom drawer can register `window.nameless.registerShopThemeScript({ open, refresh?, cartCount? })` from a script your store's Fast Bundle 2.0 configuration loads; if it fails, the shopper goes to the cart page.

## Checkout

The discount function applies rewards in **Shopify checkout**. Keep the automatic discount **FastBundle (DO NOT DELETE)** **Active** in Shopify admin → **Discounts**; don't delete or rename it.

- Every line of a bundle add carries `__FB_ATC_UID`; if a cart app or theme strips it, items stay at **full price**. Two adds of the same bundle are two bundles.
- Checkout uses the bundle's current settings. Only **Active** bundles get the discount.
- The widget doesn't show discount codes or other apps' discounts, so its total can differ from checkout. **Settings → Discount combinations** controls combining.

If the discount is missing, see [Troubleshooting](/troubleshooting#discount-missing-at-checkout).

## Subscriptions

Each line is added with the selling plan the shopper picked. When the bundle owns the theme's button, supported subscription apps' plan pickers are hidden.

## Bundle as Product

- The product can't be bought alone. On its page, **Buy it now** is hidden; with the widget's button the theme's add-to-cart is hidden too, and with the theme's button it adds the bundle.
- Elsewhere (collection pages, quick-add), adding the product sends the shopper to its page.
- No other bundle shows on its page, and it is left out of other bundles' collections.
