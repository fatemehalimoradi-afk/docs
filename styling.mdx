---
title: "Styling"
description: "Scope CSS so it only touches this bundle’s widget"
---

Root every rule at `[data-nameless-widget]`; the host scopes it to the bundle’s own widget:

```css
[data-nameless-widget] .nb-bundle {
  border: 1px solid #e2e2e2;
  border-radius: 8px;
  padding: 1.25rem;
  font-family: inherit;
}

[data-nameless-widget] .nb-item {
  display: flex;
  gap: 0.75rem;
  align-items: flex-start;
}
```

- Prefix your classes (e.g. `nb-`) and inherit typography (`font-family: inherit`).
- Don’t style bare elements (`button {}`, `img {}`, `* {}`), theme classes, or markup your renderer doesn’t emit.
- Don’t `@import` stylesheets or load remote web fonts.

Keep CSS and renderer classes in sync. Use semantic, labelled markup so the widget works unstyled.
