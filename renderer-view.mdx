`ctx.view` is everything the widget draws, with every rule and price already worked out.

## Money

```ts
interface Money {
  amount: number;   // whole number in the currency's smallest unit — for comparing only
  currency: string; // ISO 4217, the shopper's currency
  text: string;     // formatted for ctx.locale, e.g. "$16.20" — the only thing you print
}
```

- Print `.text`. Never do arithmetic on or format an amount.
- `was` and `saved` are `null` when nothing is discounted; draw one price then.
- All amounts in a view share one currency.
- The total is not the checkout total: discount codes and other apps' discounts aren't in it.

## Selectors

One selector per editor product set, in merchant order.

| Field | Meaning |
| --- | --- |
| `id` | Goes into `data-nameless-*-selector` attributes |
| `itemType` | `"product"`: one product's variants. `"collection"`: a collection's products |
| `type` | `"single"`: every unit is the same member. `"multi"`: units can mix members |
| `grouping` | What counted units share: `"variant"`, `"product"` (any of its variants), or `"general"` (any mix). Use it to word the row |
| `products` | Products loaded so far that have a variant left; empty when nothing is left to sell |
| `selections` | One entry per picked variant |
| `summary` | These picks' totals and unit count |
| `startQuantity` | Units a pick starts with; a row awaiting its pick stands for this many |
| `optionPicks` | Option name → picked value |
| `unitPicks` | `null`, or one entry per unit when each unit is picked on its own |
| `pickedLast` | The shopper changed this selector's variant last |
| `pickNeeded` | A pick is missing (an unpicked option, or after a press an unmet offer-wide condition counting this row). Name the row once `addToCart.pressed` |

Collection selectors also have:

| Field | Meaning |
| --- | --- |
| `collection` | `{ handle, title }` |
| `asPageProduct` | `true`: the page's product stands for the collection. `products` holds only it; draw and pick it like a product selector |
| `moreProducts` | `"ready"`, `"loading"`, `"failed"`, or `"none"` — see [Large collections](#large-collections) |

### What to draw

- **Product selector**, or collection with `asPageProduct: true`: one product row from `products[0]`; zero or one selection, or one per unit when `unitPicks` is set.
- **Collection, `"single"`**: one row per product; at most one selection, and a new pick replaces it.
- **Collection, `"multi"`**: one row per product; one selection per picked variant line.
- Match collection rows to selections by `productId` (and `variantId` with [variant lines](/data-attributes#variant-lines)).
- Heading: `selector.collection.title` for a collection selector, else `selector.products[0].title`.
- A product with no entry in `selections` is unpicked: draw its `defaultVariantId` variant (price, picture, stock) and mark it selected in its `<select>`.
- Picture: the picked variant's `image`, else the default variant's.
- Display `selection.quantity`; never hardcode a starting quantity.
- `view.pageProductId` is the product whose page shows the bundle (`null` off a product page).
- A row is optional when no tier's `requirements` name it with a `min` above 0.

### Options and per-unit picks

Per selector, draw either one variant dropdown or one dropdown per option (one-product rows only). See [Option dropdowns](/data-attributes#option-dropdowns).

With `unitPicks` set, draw one numbered line of option dropdowns per unit ("#1", "#2"…), reading that unit's `optionPicks` and the selection with its `unitIndex`. Put `data-nameless-unit="{index}"` on each of its `<select>`s.

### Large collections

Collection selectors load products in batches of 50. `moreProducts` is `ready` (another batch can load), `loading` (draw the button disabled), `failed` (the button retries), or `none` (all loaded; no button).

Unless it is `none`, draw one `<button data-nameless-load-more="{selector.id}">` after the rows (without it, more load on scroll, but not for rows drawn as `<option>`s). Keep row `id`s stable.

## Selections

```ts
interface ViewSelection {
  productId: string;
  variantId: string;
  quantity: number;
  planId: string | null;       // null = one-time purchase
  soldOut: boolean;            // stock can't cover every unit of this variant in the bundle
  unitIndex: number | null;    // which unitPicks entry this fills
  was: Money | null;           // line total before discount; null when nothing was taken off
  now: Money;                  // line total the shopper pays
  eachWas: Money | null;       // one unit before discount
  eachNow: Money;              // one unit: `now` shared over `quantity`, rounded
  rewardIds: string[];         // rewards that lowered a unit of this line
  usedUnits: number;           // units some tier used
  discountedUnits: number;     // units a reward lowered
}
```

`usedUnits` below `quantity`: a tier's `max` capped the line; the rest pay full price. When `discountedUnits` is below `quantity`, say so (e.g. `ctx.t("{{count}} of {{quantity}} discounted", …)`) rather than letting `eachNow` stand for every unit.

## Tiers

`view.tiers` lists every tier in merchant order. Tiers sharing an `offerId` form one ladder, smallest first.

| Field | Meaning |
| --- | --- |
| `id` | Goes into `data-nameless-tier-id` |
| `offerId` | Groups the tiers of one offer |
| `state` | `"applied"`: checkout charges it. `"met"`: it holds but isn't charged (another tier or offer took the units). `"notMet"`: it doesn't hold, or nothing it counts is picked |
| `chosen` | The shopper tapped it |
| `toAddTotal` | Fewest units a tap adds; `0` if none; `null` when adding can't meet it |
| `toAdd` | Those units by selector: `{ selectorId, count }[]` |
| `inStock` | `false` when a tap's picks exceed stock |
| `ifChosen` | The bundle after a tap: `{ summary, selections }`. `null` when a tap can't make it apply, and on a chosen tier |
| `requirements`, `rewardGroups` | What it asks for and gives — see below |

Highlight `applied` tiers (at most one per offer). With several rungs met and none chosen, the highest met rung is priced; give every rung its own control.

### Requirements — naming a tier

`requirements` is a list of alternative sets. Meeting every range in any one set meets the tier. Each range is one pool:

```ts
interface ViewCountRange {
  selectorIds: string[]; // counted together as one pool: "2 to 5 of A and B" holds on 1 A + 2 B
  min: number;           // fewest units from the pool; 0 when only max is set
  max: number | null;    // most units that count; the tier takes nothing off units above it
}
```

They don't change while the shopper picks. An empty list means no picks can meet the tier.

Write the tier name with the numbers as `ctx.t` variables, never as literals: `{{min}}+` when `max` is `null`, `{{min}}` when `min === max`, `Up to {{max}}` when `min` is 0, else `{{min}} to {{max}}`, followed by `what` — the headings of `selectorIds` joined with `ctx.t("and")`. Join a set's ranges with " + ", and sets with `ctx.t("or")`. See `countText` in [tier cards](#tier-cards).

### Rewards — what a tier gives

The shopper gets every reward of **exactly one** group in `rewardGroups`. Join several groups with `ctx.t("or")`; the group with `state: "applied"` is the one charged.

Each reward has `id`, `selectorIds` (what it lowers), `slice`, and an `outcome`. Word it as `rewardSentence` in [tier cards](#tier-cards) does; for `unknown`, say nothing or `ctx.t("Discount")`.

`slice` is `null` when the reward lowers every unit the tier used; otherwise `{ after, maxUnits, sort }`: units skipped first, then the most it lowers, cheapest first. "Buy 3, get 1 free" is 100% off with `{ after: 3, maxUnits: 1 }`.

Never derive prices from `outcome`. A reward is applied when a selection's `rewardIds` names it.

### Comparing before a tap

Show `tier.ifChosen.summary` (and `selections`, by selector id) on tier cards. An add-on tier with nothing picked is priced with one unit of each. A chosen tier has `ifChosen: null` (tapping it clears the choice); draw it from current selections and `view.summary`.

Tier controls: see [Tier controls](/data-attributes#tier-controls). Write `ctx.t("Add {{count}} more", …)` from a positive `toAddTotal`, or name each selector from `toAdd`.

## Summary

```ts
interface ViewSummary {
  was: Money | null;   // before discount; null when nothing is discounted
  now: Money;          // what the shopper pays
  saved: Money | null; // was minus now; null when nothing is saved
  unitCount: number;   // units picked
}
```

Take the footer from `view.summary`, never your own sum.

## Subscriptions

`view.subscriptions` is `null` when the bundle sells one-time only (the default). Then draw **no** plan control.

When set, draw one plan `<select>` per picked item whose chosen variant has `plans`:

- List **that item's own chosen variant's** `plans` (`name`, `price.text`); never build a shared list by hand.
- Offer one-time (`value=""`) only when the product's `subscriptionOnly` is false.
- Select what `selection.planId` holds (`null` = one-time). Never preselect a plan.

Alternatively, draw **one shared plan control** for the whole bundle, only while `sharedPlanOffered` is true. It also covers rows picked unit by unit.

| Field | Meaning |
| --- | --- |
| `sharedPlanOffered` | One choice for the whole bundle is possible (every selector draws one fixed product on this page) |
| `sharedGroups` | Selling-plan group names every picked item can be bought on now |
| `selectedGroup` | The chosen group; `null` = one-time, or items are on different groups |
| `sharedPlans` | Plans every picked unit can be bought on: `{ id, name }[]` |
| `selectedPlan` | The shared plan every picked unit is on; `null` = one-time, or units are on different plans |

Offer only `sharedGroups`; when empty, say the items share no subscription instead of drawing an empty `<select>`. Never combine per-item and shared controls. A group control puts each item on the first plan of that group its variant is sold on; to let the shopper choose a frequency, use `sharedPlans`.

## Add-to-cart state

Usage: [Renderer function → Add-to-cart button](/renderer-function#add-to-cart-button).

```ts
interface ViewAddToCart {
  enabled: boolean;         // false until something is picked, nothing is sold out, no row waits for a pick
  themeButtonAdds: boolean; // true: the theme's own button adds the bundle; draw no button
  pressed: boolean;         // pressed at least once
  adding: boolean;          // the cart call is in flight
  error: { code: "pickNeeded" | "soldOut" | "refused"; message: string | null } | null;
}
```

## Full type

```ts
interface RendererView {
  viewVersion: 2;
  bundleId: string;
  title: string; // not for drawing: write your own title with ctx.t
  selectors: ViewSelector[];
  tiers: ViewTier[];
  summary: ViewSummary;
  subscriptions: ViewSubscriptions | null;
  addToCart: ViewAddToCart;
  pageProductId: string | null;
}

type ViewSelector = ViewProductSelector | ViewCollectionSelector;

interface ViewSelectorBase {
  id: string;
  type: "single" | "multi";
  grouping: "variant" | "product" | "general";
  startQuantity: number;
  products: ViewProduct[];
  selections: ViewSelection[];
  summary: ViewSummary;
  optionPicks: Record<string, string>;
  pickedLast: boolean;
  pickNeeded: boolean;
  unitPicks: { optionPicks: Record<string, string>; pickedLast: boolean }[] | null;
}

interface ViewProductSelector extends ViewSelectorBase {
  itemType: "product";
}

interface ViewCollectionSelector extends ViewSelectorBase {
  itemType: "collection";
  collection: { handle: string; title: string };
  asPageProduct: boolean;
  moreProducts: "none" | "ready" | "loading" | "failed";
}

interface ViewProduct {
  id: string;
  handle: string;
  title: string;
  subscriptionOnly: boolean;
  options: { name: string; values: string[] }[];
  variants: ViewVariant[];
  defaultVariantId: string; // first available variant, else the first
}

interface ViewVariant {
  id: string;
  title: string; // e.g. "Red / M"
  options: { name: string; value: string }[];
  price: Money;
  available: boolean;
  inventory: number | null; // null when Shopify doesn't say
  image: { url: string; alt: string | null } | null;
  plans: { id: string; name: string; price: Money }[];
}

interface ViewTier {
  id: string;
  offerId: string;
  rewardGroups: {
    id: string;
    state: "applied" | "notApplied";
    rewards: ViewReward[];
  }[];
  state: "applied" | "met" | "notMet";
  chosen: boolean;
  toAddTotal: number | null;
  toAdd: { selectorId: string; count: number }[];
  inStock: boolean;
  ifChosen: { summary: ViewSummary; selections: Record<string, ViewSelection[]> } | null;
  requirements: ViewCountRange[][];
}

interface ViewReward {
  id: string;
  outcome:
    | { kind: "percentOff"; percent: number }
    | { kind: "amountOff"; amount: Money; per: "total" | "selector" | "unit" }
    | { kind: "setPrice"; price: Money; per: "total" | "selector" | "unit" }
    | { kind: "unknown" };
  selectorIds: string[];
  slice: { after: number; maxUnits: number | null; sort: "cheapest" } | null;
}

interface ViewSubscriptions {
  sharedPlanOffered: boolean;
  sharedGroups: string[];
  selectedGroup: string | null;
  sharedPlans: { id: string; name: string }[];
  selectedPlan: string | null;
}
```

Treat every id as opaque: copy it as given; never parse or rebuild it.

## Examples

### Tier cards

One card per tier, carrying only the tier id. `heading` is from the [minimal example](/renderer-function#minimal-example).

```js
// `heading` must guard an empty `products` list in real code.
function headingOf(selectorId) {
  for (var i = 0; i < v.selectors.length; i++) {
    if (v.selectors[i].id === selectorId) return heading(v.selectors[i]);
  }
  return "";
}

function countText(count) {
  var what = count.selectorIds.map(headingOf).join(" " + ctx.t("and") + " ");
  var vars = { min: count.min, max: count.max, what: what };
  if (count.max === null) return ctx.t("{{min}}+ {{what}}", vars);
  if (count.min === count.max) return ctx.t("{{min}} {{what}}", vars);
  if (count.min === 0) return ctx.t("Up to {{max}} {{what}}", vars);
  return ctx.t("{{min}} to {{max}} {{what}}", vars);
}

function tierName(tier) {
  return tier.requirements
    .map(function (set) { return set.map(countText).join(" + "); })
    .join(" " + ctx.t("or") + " ");
}

function rewardSentence(reward, what) {
  var o = reward.outcome;
  if (o.kind === "percentOff") return ctx.t("Save {{percent}}%", { percent: o.percent });
  if (o.kind === "amountOff" && o.per === "unit") return ctx.t("{{amount}} off each", { amount: o.amount.text });
  if (o.kind === "amountOff" && o.per === "selector") return ctx.t("{{amount}} off {{what}}", { amount: o.amount.text, what: what });
  if (o.kind === "amountOff") return ctx.t("{{amount}} off", { amount: o.amount.text });
  if (o.kind === "setPrice" && o.per === "unit") return ctx.t("{{price}} each", { price: o.price.text });
  if (o.kind === "setPrice" && o.per === "selector") return ctx.t("{{what}} for {{price}}", { what: what, price: o.price.text });
  if (o.kind === "setPrice") return ctx.t("All for {{price}}", { price: o.price.text });
  return "";
}

var tierCards = v.tiers
  .map(function (tier) {
    var sentences = tier.rewardGroups
      .map(function (group) {
        return group.rewards
          .map(function (reward) { return rewardSentence(reward, headingOf(reward.selectorIds[0])); })
          .join(", ");
      })
      .join(" " + ctx.t("or") + " ");
    var after = tier.ifChosen ? tier.ifChosen.summary : null;
    var price = after
      ? '<span class="nb-tier__price">' + esc(after.now.text) +
        (after.saved ? " <small>" + ctx.t("save {{amount}}", { amount: after.saved.text }) + "</small>" : "") +
        "</span>"
      : "";
    var hint = tier.toAdd
      .map(function (c) {
        return '<span class="nb-tier__hint">' +
          ctx.t("Add {{count}} {{what}}", { count: c.count, what: headingOf(c.selectorId) }) + "</span>";
      })
      .join("");
    var tappable = tier.ifChosen !== null || tier.chosen;
    var tag = tappable ? "button" : "div";
    return (
      "<" + tag + ' id="nb-' + esc(v.bundleId) + "-tier-" + esc(tier.id) + '"' +
      (tappable
        ? ' type="button" data-nameless-tier-id="' + esc(tier.id) + '"' +
          ' aria-pressed="' + (tier.state === "applied" ? "true" : "false") + '"' +
          (tier.inStock ? "" : " disabled")
        : "") +
      ' class="nb-tier nb-tier--' + esc(tier.state) + '">' +
      '<span class="nb-tier__name">' + tierName(tier) + "</span>" +
      '<span class="nb-tier__reward">' + sentences + "</span>" +
      price + hint +
      "</" + tag + ">"
    );
  })
  .join("");
```
