---
title: "Renderer function"
description: "Register a renderer and paint the widget from the view"
---

The bundle's **JS code** registers one renderer, which turns the **view** into HTML and computes nothing.

## Register

```js
window.nameless.defineRenderer(
  function (ctx) {
    ctx.paint("<div class='nb-bundle'>…</div>");
  },
  { viewVersion: 2 },
);
```

- Pass `{ viewVersion: 2 }` exactly, or the renderer never runs (`RENDERER_VIEW_VERSION_MISSING`).
- Call it once, at the top level — never inside `DOMContentLoaded`, `setTimeout`, a promise, or any callback.

## The context object

| Field | Type | Notes |
| --- | --- | --- |
| `view` | `RendererView` | Read-only. See [Renderer view](/renderer-view) |
| `container` | `HTMLElement` | The mount. Carries `data-nameless-widget="{bundleId}"` |
| `paint` | `(html: string) => void` | Draws your markup into `container` |
| `locale` | `string` | BCP-47 tag (`"en"`, `"pt-BR"`). Never null |
| `primaryLocale` | `string` | The shop's default language; falls back to `locale` |
| `t` | `(source, vars?) => string` | Translates your copy |
| `productUrl` | `(handle) => string \| null` | A product's page in the page's language; `null` where the surface has none |
| `collectionUrl` | `(handle) => string \| null` | The same for a collection |
| `bundlePageUrl` | `string \| null` | Always `null` for a custom renderer |
| `params`, `styleVars`, `customCss`, `widgetCopy` | | For built-in bundle-type widgets; ignore them |

## Paint

The renderer runs on mount and after every change. Each time, build the whole markup from `ctx.view` and call `ctx.paint(html)` once.

`paint` keeps elements with the same `id` as the same node, preserving open `<details>`, typed values, and focus. Give every repeated element an `id` built from `view.bundleId` and its own id:

```js
'<li id="nb-' + esc(v.bundleId) + "-row-" + esc(sel.id) + "-" + esc(product.id) + '">'
'<button id="nb-' + esc(v.bundleId) + "-tier-" + esc(tier.id) + '" …>'
```

An element under a new `id` is drawn exactly as written.

## Translate your copy

`ctx.t` uses the English source string as the key:

```js
ctx.t("Add to cart");
ctx.t("Add {{count}} more", { count: 2 });
```

It falls back to the shop's default language, then your literal, and never throws.

- Wrap every word you write in `ctx.t`. View text (titles, `Money.text`) is the merchant's: escape it instead.
- Keep existing `ctx.t` literals byte-for-byte; the literal is the key to the merchant's stored translations.
- Translate whole phrases with `{{vars}}`; never concatenate translated fragments.
- Don't fix widths for labels or buttons; translations run up to 50% longer.
- Write the bundle's title (and any subtitle) with `ctx.t`. `view.title` is not for drawing.

## Hard rules

- No `addEventListener` or inline `on*=""` handlers; use [data attributes](/data-attributes).
- No `window.nameless.dispatch(...)`, cart or Ajax calls, `fetch`, or `XMLHttpRequest`.
- No globals, `localStorage`, or timers that change state. Never cache DOM nodes between calls.
- No money arithmetic: print `Money.text`; use `Money.amount` only to compare.
- No counting: use `view.summary.unitCount` and `selector.summary.unitCount`.
- No eligibility logic: tier facts are in `view.tiers`.
- Escape every view string with an `esc()` helper like the one in the [minimal example](#minimal-example). Never escape `ctx.t` output; it escapes itself and its variables.

## Minimal example

One row per product selector, a total, and an add-to-cart button. Tier cards are on [Renderer view](/renderer-view#examples).

```js
window.nameless.defineRenderer(
  function (ctx) {
    var v = ctx.view;
    function esc(x) {
      return String(x)
        .replace(/&/g, "&amp;")
        .replace(/</g, "&lt;")
        .replace(/>/g, "&gt;")
        .replace(/"/g, "&quot;");
    }
    function heading(sel) {
      if (sel.itemType === "collection") return sel.collection.title;
      return sel.products[0] ? sel.products[0].title : "";
    }
    function variantOf(product, id) {
      for (var i = 0; i < product.variants.length; i++) {
        if (product.variants[i].id === id) return product.variants[i];
      }
      return null;
    }

    var rows = v.selectors
      .map(function (sel) {
        // A collection standing in for the page's product is drawn like a product selector.
        if (sel.itemType === "collection" && !sel.asPageProduct) return "";
        var product = sel.products[0];
        if (!product) return "";
        var picked = sel.selections[0] || null;
        var shownId = picked ? picked.variantId : product.defaultVariantId;
        var options = product.variants
          .map(function (variant) {
            return (
              '<option value="' + esc(variant.id) + '"' +
              (variant.id === shownId ? " selected" : "") + ">" +
              esc(variant.title) + "</option>"
            );
          })
          .join("");
        var price = picked
          ? (picked.eachWas ? "<s>" + esc(picked.eachWas.text) + "</s> " : "") + esc(picked.eachNow.text)
          : esc(variantOf(product, shownId).price.text);

        return (
          '<li id="nb-' + esc(v.bundleId) + "-row-" + esc(sel.id) + '" class="nb-item">' +
          '<span class="nb-item__title">' + esc(product.title) + "</span>" +
          '<span class="nb-item__price">' + price + "</span>" +
          (picked && picked.soldOut ? '<span class="nb-item__badge">' + ctx.t("Sold out") + "</span>" : "") +
          '<select data-nameless-variant-selector="' + esc(sel.id) + '">' + options + "</select>" +
          "<label>" + ctx.t("Qty") +
          ' <input type="number" min="0" step="1" value="' + (picked ? picked.quantity : 0) + '"' +
          ' data-nameless-qty-selector="' + esc(sel.id) + '"></label>' +
          "</li>"
        );
      })
      .join("");

    var hints = v.selectors
      .filter(function (sel) { return sel.pickNeeded; })
      .map(function (sel) {
        return '<p class="nb-bundle__note">' + ctx.t("Choose {{what}}", { what: heading(sel) }) + "</p>";
      })
      .join("");

    var total = v.summary.was
      ? "<s>" + esc(v.summary.was.text) + "</s> <strong>" + esc(v.summary.now.text) + "</strong>"
      : "<strong>" + esc(v.summary.now.text) + "</strong>";

    var atc = v.addToCart.themeButtonAdds
      ? ""
      : '<button type="button" class="nb-bundle__atc" data-nameless-atc="' + esc(v.bundleId) + '"' +
        (v.addToCart.enabled ? "" : " disabled") +
        (v.addToCart.adding ? ' aria-busy="true" aria-disabled="true"' : "") + ">" +
        (v.addToCart.adding ? ctx.t("Adding to cart…") : ctx.t("Add to cart")) +
        "</button>";

    ctx.paint(
      '<div class="nb-bundle">' +
        '<h3 class="nb-bundle__title">' + ctx.t("Build your bundle") + "</h3>" +
        '<ul class="nb-bundle__list">' + rows + "</ul>" +
        hints +
        '<p class="nb-bundle__total">' + ctx.t("Total") + " " + total + "</p>" +
        atc +
      "</div>",
    );
  },
  { viewVersion: 2 },
);
```

## Add-to-cart button

Draw one `<button data-nameless-atc="{view.bundleId}">` from `view.addToCart`:

| Field | What to do |
| --- | --- |
| `themeButtonAdds` | `true`: the theme's button adds the bundle. Draw **no** button; the host removes any stray `[data-nameless-atc]` |
| `enabled` | `false` until something is picked, nothing is sold out, and no row awaits a pick. Disable the button, or keep it pressable and point out what's missing once `pressed` |
| `pressed` | From then on, name each `pickNeeded` row and sold-out selection |
| `adding` | Request in flight (clicks ignored). Add `aria-busy="true" aria-disabled="true"` and a spinner or `ctx.t("Adding to cart…")`, keeping the button's size |
| `error` | The last press added nothing; say why near the button. `pickNeeded`: ask for the missing picks. `soldOut`: part is sold out. `refused`: print `error.message` (already translated) if not null, else a general message |

Draw busy and error states yourself; the runtime writes nothing into the button. `themeButtonAdds` is `true` only when the add-to-cart method is the theme button and the widget sits inline on the product page; trust the flag. See [Shopify integration](/shopify-integration#add-to-cart-method).

## When things go wrong

The host logs these codes prefixed with `[FastBundle]`:

| Code | Meaning | Effect |
| --- | --- | --- |
| `RENDERER_THREW` | Your callback threw | Theme elements the bundle hid come back; the container keeps its last paint |
| `RENDERER_LOAD_ERROR` | The CSS or JS failed to load | Not rendered |
| `RENDERER_VIEW_VERSION_MISSING` | `defineRenderer` called without `viewVersion`, or never called | Theme's page shown |
| `RENDERER_VIEW_UNSUPPORTED` | `viewVersion` the host doesn't build | Theme's page shown |
| `RENDERER_MOUNT_NOT_FOUND` | No `[data-nameless-block]` mount for this bundle | Renderer never called |
| `RENDERER_MISSING` | The bundle names no JS file | Theme's page shown |
| `RENDERER_EMPTY` | A bundle-type widget drew nothing (not for custom renderers) | Theme's page shown |
| `VIEW_BUILD_FAILED` | The view couldn't be built | Theme's page shown. Contact support |

If the CSS fails, the JS isn't run. Guard against empty `selectors`, `products`, and `selections`, and `null` images and money.
