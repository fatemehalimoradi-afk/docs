Fast Bundle 2.0 is a Shopify app for selling product bundles with automatic discounts. Shoppers pick the bundle on the product page, and the discount is applied at Shopify checkout.

You create a bundle in two ways:

- **From a bundle type** — pick a ready form such as **Fixed bundle**, fill it in, and Fast Bundle 2.0 builds both the discount logic and the widget.
- **With the Bundle Engine** — describe the bundle to the AI, or build it by hand. You control every piece: the products, the offers and their tiers, the conditions, the rewards, and the widget's code.

Either way, every bundle is the same model underneath: **product sets**, **offers** made of **tiers**, **conditions**, **rewards**, and the **widget**.

To see live bundles built with Fast Bundle 2.0, browse the [bundle catalog](https://demo.fastbundle.co/pages/bundle-catalog) on our demo store.

## Names you'll see

Fast Bundle 2.0 is the product. Its engine is called **Nameless** internally, and that name appears wherever a theme or code refers to the engine directly. Keep these identifiers exactly as they are — integrations depend on them:

| Where | Name |
| --- | --- |
| Theme editor | The **Nameless Bundles** app embed and the **Nameless** app block |
| Widget code | `window.nameless`, `data-nameless-*` attributes, `[nameless]` console messages |
| Cart lines | The `__FB_ATC_UID` line-item property |
| Shopify admin → Discounts | Fast Bundle 2.0's automatic discount, **FastBundle (DO NOT DELETE)** |
