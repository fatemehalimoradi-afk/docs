Fast Bundle 2.0 is a Shopify app for selling product bundles with automatic discounts. Shoppers pick the bundle on the product page; the discount applies at Shopify checkout.

Create a bundle in one of two ways:

- **From a bundle type** — fill in a ready form such as **Fixed bundle**. Fast Bundle 2.0 builds the discount logic and the widget.
- **With the Bundle Engine** — describe the bundle to the AI, or build it by hand, and control every piece.

## Names you'll see

Some identifiers use the engine's internal name, `nameless`. Keep them exactly as they are:

| Where | Name |
| --- | --- |
| Theme editor | The **Bundles** app embed and the **Bundle** app block |
| Widget code | `window.nameless`, `data-nameless-*` attributes, `[FastBundle]` console messages |
| Cart lines | The `__FB_ATC_UID` line-item property |
| Shopify admin → Discounts | The automatic discount **FastBundle (DO NOT DELETE)** |
