---
title: "Build a custom widget"
description: "From an empty bundle to a verified checkout discount, step by step"
---

Build a "buy more, save more" bundle with your own widget code. You need Fast Bundle 2.0 installed with the **Bundles** app embed on — see [Getting started](/getting-started).

<Steps>
  <Step title="Create the bundle">
    In Fast Bundle 2.0, click **Create bundle** → **Build with AI** → **Make it manually here**. In the **Form** tab:

    1. **Name**: `Walkthrough`. **Discount label**: `Buy more, save more`.
    2. **Products used in logic** → **Add product** (one with a few variants); **Matching items must be**: **The same variant**.
    3. **Set up an offer for this bundle**. Tier #1: condition **At least** 2 of that product, reward **Percentage discount** 10%.
    4. **Add tier**. Tier #2: **At least** 4, **Percentage discount** 20%.

    Leave the status on **Draft** and save.
  </Step>
  <Step title="Add the widget code">
    In **Display options → Product detail page → Code**, paste the [minimal example](/renderer-function#minimal-example) into **JS code** and this into **CSS code**:

    ```css
    [data-nameless-widget] .nb-bundle { border: 1px solid #ddd; border-radius: 8px; padding: 1rem; font-family: inherit; }
    [data-nameless-widget] .nb-item { display: flex; gap: 0.75rem; align-items: center; flex-wrap: wrap; }
    [data-nameless-widget] .nb-bundle__atc { width: 100%; margin-top: 0.75rem; padding: 0.75rem; }
    ```

    Save and check the **Preview**.
  </Step>
  <Step title="Add tier cards">
    Add the [tier cards](/renderer-view#tier-cards) helpers inside the renderer function and put `tierCards` above the list:

    ```js
    '<div class="nb-tiers">' + tierCards + "</div>" +
    ```

    The **Preview** shows "2+" and "4+" cards; tapping one meets it and marks it applied.
  </Step>
  <Step title="Preview on your store">
    Open the product page with `?nameless_preview=true`. In the console, run:

    ```js
    window.nameless.subscribe("bundles", console.log);
    ```

    Check that `tiers[].state` follows your quantity and `summary.saved` appears at 2 or more. Previews add at **full price**.
  </Step>
  <Step title="Activate and test the discount">
    Set **Status: Active**, save, and wait for **Synced**. Without the preview parameter, add quantity 4 to the cart: the line shows 20% off.
  </Step>
  <Step title="Verify the order">
    Place a test order. In Shopify admin → **Orders**, the line shows `__FB_ATC_UID` and the discount under your label. If missing, see [Troubleshooting](/troubleshooting#discount-missing-at-checkout).
  </Step>
</Steps>

Before you ship, run the [pre-ship checklist](/runtime-api#pre-ship-checklist).
