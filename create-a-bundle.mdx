Click **Create bundle**, then on **Choose bundle type** pick a bundle type card → **Choose** (and a preset, if offered), or click **Build with AI**. Cards marked **Coming soon** can't be built yet.

## From a bundle type

Each type has its own form. A **Fixed bundle**:

1. **The offer** — **Included products** (at least 2) and a **Discount** with **Discount type**: **Percentage off**, **Fixed discount**, **Set price**, **Free shipping**, or **No discount**.
2. **Display options → Upsell on included product pages** — **Title** and **Visibility**.
3. **Bundle as Product** and **Extras → Subscription** (optional).
4. **Settings** — **Name** (only you see it), price display (**Show price per item**, **Unit label**), and variant choice (**Let customers choose different variants for each item**).
5. **Style** — see [Styling a bundle type](#styling-a-bundle-type).
6. **Content and translations** — wording per store language.

It starts as **Active**. Save to publish; the badge shows **Syncing with Shopify**, then **Synced**. **Apply the bundle discount to** (under **Subscription**) is store-wide, like **Settings → Subscription discount**. Position and hidden elements come from [Store-wide settings](#store-wide-settings).

### Mix and match

- **Steps** — each **Step #N** has a **Title**, optional **Description** and **Image**, a collection, and **Rules**: **Exact**, **Minimum**, **Range**, or **Optional** (with an optional maximum). **Add step** adds another.
- **Discount** — tiers by item count (**Exactly**, **Between**, or **Minimum** for the last tier), each with **Percentage discount**, **Fixed discount**, **Set price**, **Cheapest item free**, **Free shipping**, or **No discount**.
- **Bundle builder → Product layout** — **Built into product page** (next to the product images) or **Expanded builder** (replaces the bundle's product page; a bundle without a product opens on its own **Bundle page**).
- **Upsell on included product pages** — **Build on the page** or **Go to bundle builder**.
- **Extras** — an **Add-on** block and a **Subscription** section.

### Styling a bundle type

The **Style** card sets **Color**, **Typography**, **Spacing** (corner radius), and **Custom CSS** in two tabs: **Global theme** (every bundle using it) and **Custom design** (this bundle only; wins over the global theme).

Shared wording such as "Add to Cart" is under **Translate shared texts of all bundles** → **Open editor**. **Settings → Bundle types → Republish all bundles** rebuilds every bundle type bundle's storefront data.

## With the Bundle Engine

In **Generate Your Bundle with AI**, describe the bundle (mention products and collections, or attach an image) and click **Generate bundle**, or choose **Make it manually here**. The editor has a live **Preview**, an **AI chat** tab for changes in plain words, and a **Form** tab. It starts as **Draft**.

### The Form tab

| Card | What you set |
| --- | --- |
| General | **Name** (only you see it) and **Discount label** (shown next to the discount in cart and checkout) |
| **Products used in logic** | Product sets — see [Bundle concepts](/bundle-concepts) |
| Offers | **Set up an offer for this bundle**, **Add tier**, and each tier's **Conditions** and **Rewards** |

### Display options

Under **Display options → Product detail page**:

| Setting | Options |
| --- | --- |
| **Show this bundle on product pages** | On by default |
| **Show on** | **All the included product pages** or **Selected products' pages** |
| **Display as** | **Inline widget** (default) or **Pop-up**. **Pop-up** replaces position and add-to-cart method with **Pop-up trigger: Theme add-to-cart button** |
| **Widget position** | **Above** or **Below** (default) the **Theme's add-to-cart button**, or a **Custom element** by CSS selector |
| **Add-to-cart method** | **Using widget button** (default) or **Using theme button**. See [Add-to-cart method](/shopify-integration#add-to-cart-method) |
| **Code** | **JS code** and **CSS code**. See [Widget](/widget) |
| **Content and translation** | Wording per language; **Translate EN → FR** fills empty fields |
| **App block** | A **Display handle** for the theme's app block. See [Placing the widget](/shopify-integration#placing-the-widget) |
| **Advanced** | **Display priority** (default 1; lower shows first) and **Hide elements** (CSS selectors) |

### Bundle as Product

The **Bundle as Product (BAP)** card creates a Shopify product and page for the bundle.

- **Product title** and **Price** are required; **Compare-at price** must be higher than the price.
- Its page has its own **Widget position**, **Add-to-cart method**, **Code**, **Content and translation**, and **Hide elements**; without code it uses the product page's code.
- **Turn off and delete** deletes the product from Shopify; orders are not affected. Drafting or archiving the product turns the bundle off.

See [Bundle as Product](/shopify-integration#bundle-as-product).

### Subscriptions

Turn on **Let customers buy this bundle on a subscription** to offer each product's selling plans.

## Status and publishing

- **Active** — shows on the store and gets the checkout discount.
- **Draft** — hidden. Preview it with `?nameless_preview=true` on a product URL (or **View on store**). Previews don't get the discount.

**Bundle needs a UI** after saving means there's no widget code yet. If a save is refused for size, see [Troubleshooting](/troubleshooting#save-is-refused).

## Store-wide settings

In **Settings**:

| Setting | What it does |
| --- | --- |
| **Default widget position** | Default CSS selector and **Position**: **Each bundle's own position** (default), **Above the element**, or **Below the element**. **Advanced** sets one per bundle type |
| **Hide elements** | Theme elements every bundle hides. **Advanced** adds a list per bundle type |
| **Widget button action** | After the widget's button adds: **Cart drawer** (default), **Checkout**, **Cart page**, or **Do nothing**. **Advanced → Don't use the theme's add-to-cart button** makes every bundle use its own button |
| **Subscription discount** | **First payment only** (default), **Multiple recurring payments** (with a number of **Payments**), or **All recurring payments** |
| **Discount combinations** | Combine with **Product discounts**, **Order discounts**, **Shipping discounts** (all on by default) |
