## Checklist

1. Fast Bundle 2.0 is installed and has been **opened once** in Shopify admin.
2. The **Bundles** app embed is on.
3. The bundle is **Active**, and **Show this bundle on product pages** is on.
4. The editor shows **Synced**, not **Syncing with Shopify** or **Sync failed**.
5. The product you test matches one of the bundle's product sets.
6. **FastBundle (DO NOT DELETE)** is **Active** in Shopify admin → **Discounts**.
7. No plan or billing banner shows in the admin.

## Plan and billing

| Banner | Meaning | What to do |
| --- | --- | --- |
| **Approve your plan to show your bundles again** | No active subscription; bundles hidden | **Approve in Shopify** |
| **Your plan approval is waiting in Shopify** | Approval not finished | **Finish approval in Shopify**, or choose a plan |
| **Keep your bundles live — upgrade within N days** | Revenue allowance reached; grace period running | Upgrade before it ends |
| **Your bundles are paused** | Grace period ended; displays and discounts stopped | Upgrade, or wait for the next revenue cycle |
| **Upgrade to activate this bundle** | Plan excludes Bundle Engine form bundles (Draft still works) | **Upgrade to Enterprise** |

## Install didn't create the discount

A discount titled **FastBundle (DO NOT DELETE)** already exists. Delete or rename it in Shopify admin → **Discounts**; Fast Bundle 2.0 retries once a day.

## Widget does not appear

| Symptom | Likely cause | What to do |
| --- | --- | --- |
| Blank on a Liquid product page | App embed off, or product not in an active bundle | Turn on the **Bundles** embed; check the bundle |
| Shows on some products only | **Show on → Selected products' pages** | Check the selected product sets |
| A different bundle shows | Several match; lower priority shows first | Adjust **Display priority** |
| Widget in the wrong place | No position matched the theme | Set **Widget position → Custom element**, or use the [app block](/shopify-integration#the-app-block) |
| Old content after an edit | Sync running, or browser cache | Wait for **Synced**; reload in a private window |
| Draft bundle not visible | Drafts are hidden | Add `?nameless_preview=true` to the URL |
| Blank iframe (headless / Tapcart) | Wrong `shop` domain, or embed origin blocked | Use `{store}.myshopify.com`. On "refused to connect", allow `https://app.fastbundle.co` |
| Headless `APP_NOT_INSTALLED` | Storefront token not provisioned | Open Fast Bundle 2.0 once in Shopify admin |
| Headless `INVALID_PARAMS` | Missing or invalid `shop` | Pass `shop=your-store.myshopify.com` |
| `[FastBundle] RENDERER_THREW` | The renderer threw | Fix the JS code. See [Renderer function](/renderer-function#when-things-go-wrong) |
| `[FastBundle] RENDERER_LOAD_ERROR` | CSS or JS failed to load | Fix the failing file |
| `[FastBundle] RENDERER_VIEW_VERSION_MISSING`, or preview "This renderer is out of date" | `defineRenderer` called without `viewVersion` | Pass `{ viewVersion: 2 }`, or ask the assistant to regenerate the widget |
| `[FastBundle] RENDERER_VIEW_UNSUPPORTED`, or preview "This renderer can't be shown" | Unsupported `viewVersion` | Pass `{ viewVersion: 2 }`, or ask the assistant to regenerate the widget |
| `[FastBundle] RENDERER_MOUNT_NOT_FOUND` | No `[data-nameless-block]` on the page | Turn on the app embed |

## Add to cart fails

- **Liquid:** the widget shows why (missing pick, sold out, or Shopify's message); with the theme button, the theme's add is refused too. `PLUGIN_BLOCKED` in the console means a plugin blocked it. See [Add-to-cart method](/shopify-integration#add-to-cart-method).
- **Headless:** reply to `addToCart` with `addToCartResult` within 10 seconds. See [postMessage bridge](/headless-bundles-api#postmessage-bridge).
- **Tapcart:** publish the app after adding the block, and test on a device.

## Save is refused

"This shop's active bundles need … bytes…": your **Active** bundles together are too large. Deactivate one, make one smaller, or name fewer collections. Drafts don't count.

## Discount missing at checkout

1. **FastBundle (DO NOT DELETE)** is **Active** in **Discounts**, and the bundle is **Active** (previews add at full price).
2. A test order from the widget shows `__FB_ATC_UID` and the discount on each bundle line in **Orders**.
3. With another discount in the cart, check **Settings → Discount combinations**.

| Surface | What must happen |
| --- | --- |
| Liquid theme | Cart apps keep line-item properties |
| Headless embed | Your handler passes `attributes` through. See [Embed mode](/headless-bundles-api#embed-mode) |
| Custom cart / Hydrogen | Your cart API keeps line-item properties through checkout |

Other causes:

- **The cart changed after the add.** Lowering a quantity can lose the tier; raising it doesn't move up a tier. Units above a maximum pay full price.
- **The bundle was edited after the add.** Checkout uses the current settings.
- **Buy X, get Y** discounts only Y units, cheapest first.

## What to send support

Your `myshopify.com` domain, product handle or ID, page or endpoint URL, the JSON error or `[FastBundle]` console logs, and a screenshot or recording.
